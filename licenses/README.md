# Third-party licenses

## Noto Sans — SIL Open Font License 1.1

`crates/core/src/render/glyphs.rs` is generated by `tools/fontgen` and contains
glyph outlines extracted from Noto Sans. That makes it a derivative of the font,
so the OFL text ships with it — see [`NotoSans-OFL.txt`](NotoSans-OFL.txt).

The OFL permits embedding and redistribution. The one rule worth knowing if you
swap the typeface: a derivative may not be distributed under the reserved font
name, which is why the generated table is a coordinate table rather than a font
file, and why nothing here is presented as "Noto Sans".
